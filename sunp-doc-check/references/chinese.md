# 中文语法与标点

审查简体中文表达是否符合中文习惯与通行规范。规则已列全，按本清单执行，审查时不需访问外部链接；规则出处见本 skill 的参考资料台账。只报确实存在的问题。

## 字间距

- 全角中文字符与半角英文字符之间留一个半角空格：「启动 Windows 系统」，不写「启动Windows系统」
- 中文与阿拉伯数字之间的空格风格全篇统一，不混用
- 半角英文字符和数字与全角标点之间不留空格：「MacBook Air。」不写「MacBook Air 。」
- 英文单位与前面的数字之间留适当空隙：「16 GB」

## 句子长度

- 不含标点的句子或逗号分隔的构件，尽量在 20 字以内；20～29 字可接受；30～39 字须语义明确；40 字以上不可接受
- 逗号分隔的长句总长不超过 100 字或正文 3 行
- 避免「一逗到底」：整段除结尾外全部用逗号停顿时，改为拆分句子或用分号

## 用词与指代

- 用现代汉语常用表达，不用冷僻、生造或文言词语：「仅有的两种」不写「唯二的」
- 「的、地、得」用对：形容词＋的＋名词、副词＋地＋动词、动词＋得＋副词
- 代词「其、该、此、这」指代必须明确且只有一个含义；有歧义时改为重复名词
- 名词前不堆砌过多形容词，长定语拆成短句
- 不使用「底层逻辑」「闭环」「抓手」「对齐一下」等不传递具体信息的表达
- 不使用感叹语气和感叹号；不多个感叹号连用

## 肯定与否定

- 同一意思尽量用肯定句：「请确认装置的电源已关闭」不写「请确认没有接通装置的电源」
- 避免双重否定：「用户必须拥有删除权限」不写「没有删除权限的用户不能删除」

## 标点

- 中文语句用全角标点；整句英文用半角标点
- 句号、问号、叹号、逗号、顿号、分号和冒号不出现在一行之首
- 中文语句结尾用全角句号；句末括号加注时句号在括号外
- 并列词用全角顿号「、」，不用逗号，即使并列词含英文：「Google、Facebook、腾讯」；英文句子里并列词用半角逗号
- 并列词最后一项尽量用「和」连接
- 分号表示复句内部并列分句之间的停顿；避免「一逗到底」
- 引用用全角双引号，引号内再用引号时内层用单引号
- 句号、问号、叹号、逗号、顿号、分号、冒号不出现在标题末尾；引号、括号、破折号、省略号、书名号等标号可以
- 括号补充用全角圆括号，前后不加空格
- 省略号用「⋯⋯」，占两个汉字空间、六个省略点；不用「。。。」或「...」，且不与「等」连用
- 语气平静，避免感叹号和多个感叹号连用
- 破折号用「————」占两个汉字位置；只占一字位置时前后留一个半角空格
- 名词复合、图表编号用直线连接号「-」：「氧化-还原反应」「图 1-1」
- 表示时间的冒号用半角：「8:00」；表示解释的冒号用全角
- 数值范围用「～」或「—」，也可用「至」代替；两端都带单位或百分号：「132 kg～234 kg」「67%～89%」
- 阿拉伯数字一律半角；千位以上加半角逗号
- 货币用阿拉伯数字，数字前写货币符号或数字后写货币中文名称
- 数字增加用「增加了／增加到」，减少用「降低了／降低到」；「了」表增量、「到」表定量；不用「降低 N 倍」

## 英文与中文混排

- 外文缩写可用半角圆点表示，如 `U.S.A.`、`Apple, Inc.`
- 英文缩写首次出现时在括号中给出全称和中文标注，之后可直接用缩写
- 英文省略号改为中文省略号；英文书名或影片名改用中文表达时用书名号
- 英文原文复数形式译为中文时还原为单数
- 专有名词各词首字母大写，非专有名词不大写
