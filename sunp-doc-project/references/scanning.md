# 扫描步骤

阶段一只读扫描，不修改仓库任何文件，不执行会改变仓库状态的命令；辅助理解时优先用只读命令。

## 扫描顺序

1. 仓库根：README、构建文件、目录结构、工程文档
2. 应用入口：启动类、main 方法、容器配置、启动脚本
3. 模块与依赖：模块划分、内部依赖、外部依赖声明
4. 配置：配置文件、环境差异、功能开关
5. 数据：数据库定义、ORM 映射、建表脚本、缓存结构
6. 接口与交互：HTTP/RPC 接口、消息、定时任务、事件、回调
7. 代码组织：核心包、关键类、测试位置

中等项目走完一遍；超大项目按模块抽样，并在选项中说明覆盖范围有限。

## 证据

结论要能回到源码或配置：给出路径、类名、方法名；行号无法可靠确认时不写。区分已核实与推断，证据不足标为待确认，不凭类名或注释断言功能已上线。
