# sunp-skills

个人日常开发的 skill 集合。按 [工作场景](工作场景.md) 组织，每个 skill 采用标准目录结构：`<skill-name>/SKILL.md`，按需附带 `references/` 与 `examples/`。

## Skills

| Skill | 对应场景 |
|---|---|
| [`sunp-doc-project`](sunp-doc-project/SKILL.md) | 生成项目现状文档 |
| [`sunp-doc-feature`](sunp-doc-feature/SKILL.md) | 生成指定功能现状文档 |
| [`sunp-doc-check`](sunp-doc-check/SKILL.md) | 文档表达、语法、风格与阅读体验审查 |

## 加载

按所用 AI 工具的 skill 加载约定放置 skill 目录。本机已存在的 skills 目录（供参考）：`~/.config/opencode/skills`、`~/.agents/skills`、`~/.codex/skills`。
