# sunp-skills 一页速览

## 结论

截至 2026-11-24，本仓库是个人日常开发用的 skill 集合，按工作场景组织，供开发者接手项目、梳理功能与审查文档时加载。已建 3 个 skill，另有 2 个场景待建，处于持续补充阶段。

## 技术栈

仓库为纯 Markdown 目录，不含业务代码与构建系统。每个 skill 以 `SKILL.md` 定义，YAML frontmatter 声明名称、描述与元数据；细节拆到 `references/`、`examples/`、`evals/`。无第三方依赖声明。定位依据：`README.md`（Skills 表、加载节）。

## 边界

仓库不存放业务代码，不定义构建、测试与启动流程，不提供运行时服务。`sunp-doc-project`、`sunp-doc-feature`、`sunp-doc-check` 覆盖文档生成与审查；代码风格审查、代码逻辑审查两个场景尚未建立，见 `工作场景.md`（场景表）。
