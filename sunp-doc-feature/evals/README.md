# 评测场景

这些场景用来验证 `sunp-doc-feature` 是否按预期工作：先确认范围、按主题拆成独立文档、跨进程以功能为主线串联。场景中的 `files` 是占位路径，替换为真实样例仓库后才能运行评测。目前没有内置运行器，按下列步骤人工或自建脚本核验。

## 用法

1. 在 `scenarios.json` 的 `files` 字段填入对应的样例仓库路径。
2. 不加载 skill，让 AI 直接执行 `query`，记录失败项作为基准。
3. 加载 skill 后重跑同一 `query`，逐条对照 `expected_behavior`。
4. 只把能稳定复现的行为写回 skill；改动后重跑全部场景，确认没有回退。
