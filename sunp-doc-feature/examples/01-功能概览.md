# 批量调拨 概览

## 结论

批量调拨把库存数量从一个仓库转到另一个仓库，供仓管员在同组织内调整库存时使用；跨组织调拨不在此功能范围内。

## 触发方式

HTTP `POST /api/batch-transfer`，入口位于 `wms-web/src/controller/BatchTransferController.java#transfer`。

## 主流程一句话

接收调拨单 → 校验库存与操作权限 → 生成调拨明细 → 更新两个仓库的库存 → 记录调拨流水。

## 涉及范围

| 项目 | 角色 | 涉及模块 |
| --- | --- | --- |
| wms-web | 入口方 | 调拨 Controller、调拨页面 |
| wms-service | 服务方 | 调拨 Service、库存 Service |
