# 批量调拨 流程与逻辑

## 结论

调拨流程以库存校验为界：校验通过才生成明细并更新库存，校验失败直接返回错误码，不产生任何库存变动。

## 主流程

1. 接收调拨单（来源仓库、目标仓库、物料与数量）
2. 校验操作权限与来源仓库库存
3. 生成调拨明细，锁定来源仓库库存
4. 更新两个仓库的库存数量
5. 记录调拨流水，返回结果

关键代码位置：`wms-service/src/service/BatchTransferService.java#transfer`。

## 关键分支

| 分支 | 触发条件 | 处理 | 代码位置 |
| --- | --- | --- | --- |
| 库存不足 | 来源仓库可用量小于调拨量 | 返回错误码 `INSUFFICIENT_STOCK`，不生成明细 | `BatchTransferService.java#checkStock` |
| 无操作权限 | 用户不属于来源仓库 | 返回 403 | `BatchTransferController.java#transfer` |
| 仓库不存在 | 目标仓库 id 无效 | 返回错误码 `WAREHOUSE_NOT_FOUND` | `BatchTransferService.java#validateWarehouse` |

## 业务规则

- 调拨数量必须为正整数，且不超过来源仓库可用库存。
- 同一物料在同一仓库的调拨请求按提交顺序串行处理，避免超扣。
- 调拨流水一经生成不可修改，冲销通过反向调拨单完成。

## 关键实现点

### 数据转换
有：物料编码在入口处由名称转换，转换逻辑见 `wms-service/src/converter/MaterialConverter.java#toCode`。

### 校验规则
有：权限、库存、仓库有效性、数量范围四项校验。

### 校验失败处理
有：校验失败中断流程并返回错误码，不生成调拨明细。

### 状态流转
有：调拨单状态为「待处理 → 处理中 → 已完成 / 已失败」，非法转换被拒绝。

### 外部交互
没有：本功能不调用外部系统。

### 边界条件
有：并发调拨串行处理；部分更新失败时整体回滚。
