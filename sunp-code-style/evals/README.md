# 评测场景说明

本目录用于验证 `sunp-code-style` 的实际行为。

## 运行前置

`scenarios.json` 中的 `files` 字段为占位路径，替换为真实样例代码仓库后才能运行评测。样例需覆盖多种语言与下列边界。

## 期望行为

- 只输出问题清单，不修改任何代码
- 按项目配置与文件扩展名识别语言，多语言项目按文件分别套规则
- 无法识别语言时只套通用规则，并在交付说明中列出未识别文件
- Java 审查同时套用 Google Java Style 与项目自定义要求
- 问题按必须改、建议改、Nit 分级排序，每条给出位置、依据与改法
- 只报确实存在的问题，不为凑数制造问题
- 事实或逻辑疑点单列，不计入风格问题
