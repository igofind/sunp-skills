# sunp-code-style 参考资料

规则中的缩进、列宽采用项目约定值，与来源规范的原文可能不同；本表记录的是来源规范本身的要点。

## 逐项说明

### 1. Google Engineering Practices — Code Review

- 参考内容：审查标准、审查内容、写法建议三篇
- 重点：目标是提升整体代码健康、追求持续改进而非完美；技术事实优先于个人偏好；风格以规范为权威；评论针对代码不针对人，说明原因，标注必须改与可选建议
- 来源：`google/eng-practices` 仓库 `review/reviewer/` 下 `standard.md`、`looking-for.md`、`comments.md`

### 2. Google Java Style Guide

- 参考内容：Java 源文件结构、格式、命名、编程实践与 Javadoc
- 重点：UTF-8、导入不用通配符、2 空格缩进、列宽 100、覆写加 `@Override`、异常不忽略
- 来源：`google/styleguide` 仓库 `javaguide.md`

### 3. Google TypeScript Style Guide

- 参考内容：TypeScript 结构、语言特性、类型系统、注释与策略
- 重点：优先类型推断、优先 interface、限制 `any` 与包装类型、顶层导出文档化
- 来源：`google/styleguide` 仓库 `tsguide.md`

### 4. Google JavaScript Style Guide

- 参考内容：JavaScript 结构、格式、语言特性、命名与 JSDoc
- 重点：UTF-8、ES 模块、2 空格缩进、列宽 80、相等检查、禁用特性
- 来源：`google/styleguide` 仓库 `jsguide.md`

### 5. Airbnb JavaScript Style Guide

- 参考内容：JavaScript 变量、函数、模块、空白与命名等补充规则
- 重点：优先 `const`、字面量、解构、模板字符串、ES 模块
- 来源：`airbnb/javascript` 仓库 `README.md`

### 6. PEP 8

- 参考内容：Python 排版、命名、注释与编程建议
- 重点：4 空格缩进、行宽 79、文档字符串与注释 72、优先级为模块内一致高于规范一致
- 来源：`peps.python.org/pep-0008/`

### 7. Google Python Style Guide

- 参考内容：Python 语言实践与文档
- 重点：lint、导入形式、不用可变默认参数、异常不忽略、类型注解
- 来源：`google/styleguide` 仓库 `pyguide.md`

### 8. 项目全局提示词

- 参考内容：Java 代码结构、命名、注释与复杂度的自定义要求
- 重点：最小充分实现、调用可达性、参数与分支必要性、抽象与配置有据、防御指向具体失败来源；注释写语义，新增符号写 1-2 句说明表示什么、是什么、做什么，改实现同步更新
- 来源：`~/.copilot/copilot-instructions.md`「代码」节
